# economy-mode для Claude Code

Скилл-дисциплина экономного расходования токенов для длинных отладочных сессий.
Родился из разбора реальной сессии глубокой отладки, которая сожгла 5-часовой лимит
за 3 часа: 73% ушло на 174 Bash-раундтрипа интерактивного цикла «клик → кадр →
проверка» при контексте ~200k, ещё 15% — на 67 скриншотов, прочитанных в чат.

Главный вывод, который скилл закрепляет: **лимит жгут не отдельные операции, а число
раундтрипов × размер контекста главной сессии**. Каждый тулколл в разросшейся сессии
оплачивается как перечитывание всей её истории.

## Правила

- **Лестница моделей**: главная сессия — только анализ и решения; Opus-сабагент —
  сложные автономные подзадачи; Sonnet-сабагент — механика с суждением (вождение
  тестовых стендов, серии грепов, черновики); Haiku — чистая механика.
- **Интерактивные циклы — всегда в сабагенте**: его раундтрипы живут в маленьком
  отдельном контексте, наружу выходит отчёт в 10 строк.
- **Скриншоты**: первичная сверка — маркеры в логе; кадр смотреть только при провале
  проверки и после уменьшения; сериям кадров место в сабагенте.
- **Большие выводы** — в файл, в чат только grep-сводку; независимые команды батчить.
- **Стоп-правило**: две итерации без прогресса на интерактивной задаче → остановиться
  и переформулировать подход, не долбить.
- **Локальная LLM (ollama)** — текстовая разметка/классификация через скрипт; точные
  подсчёты — никогда (это grep/python); для батчей строго отключать размышления.
- **Переделки дороги**: скриптованный маршрут сначала прогонять с покадровой сверкой.

Подробности, цифры и таблица красных флагов — в [skills/economy-mode/SKILL.md](skills/economy-mode/SKILL.md).

## Установка

```bash
git clone https://github.com/Rufim/claude-economy-mode && cd claude-economy-mode && ./scripts/install.sh
```

Ставит симлинк в `~/.claude/skills/economy-mode`. Каталог назначения переопределяется
переменной `CLAUDE_SKILLS_DIR`.

## Проектные расширения

Общий скилл держит только универсальные правила. Проектную конкретику (шаблон промпта
стенд-сабагента, словарь команд стенда, ловушки конкретного движка) кладите докой в
папку проекта и ссылайтесь на неё из раздела «Проектные шаблоны» скилла — в этом репо
такой раздел ссылается на локальную доку стендов xsystem4 как на образец.

Раздел про локальную модель откалиброван под gemma4:26b (num_ctx=32768, think=false
для батчей) — под свою модель перепроверьте те же три вещи: обрезку контекста,
поведение режима размышлений на батчах и точность подсчётов.
